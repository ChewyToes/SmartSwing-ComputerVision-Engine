# SmartSwing-ComputerVision-Engine
Real-time golf swing analysis utilizing MediaPipe Pose and OpenCV
Project: SmartSwing Golf Analysis Prototype
Author: Armaan Manohar Singh

OVERVIEW:
This solution implements a real-time computer vision pipeline for golf swing analysis using MediaPipe and OpenCV. It fulfills the assignment requirements for Swing Detection, Biomechanical Analysis, Scoring, and Progress Tracking.

FILES:
1. SmartSwing_Engine.ipynb: The main source code (Jupyter Notebook).
2. swing_history.csv: The database file generated by the tracking system.
3. progress_chart.png: The visualization of user improvement.

HOW TO RUN:
1. Open 'SmartSwing_Engine.ipynb' in Google Colab or Jupyter Lab.
2. Upload a golf swing video (e.g., 'golf_swing2.mp4') to the runtime environment.
3. Update the video path in the final cell: analyzer.process_video('your_video.mp4')
4. Run all cells. 
   - The system will output an analyzed video file ('output_swing_final.avi').
   - It will update the CSV database.
   - It will generate a new 'progress_chart.png' based on the run results.

DEPENDENCIES:
- opencv-python
- mediapipe
- matplotlib
- numpy
